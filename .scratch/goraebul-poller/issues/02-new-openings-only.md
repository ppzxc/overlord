# 02: 새 빈자리만 알리고, 전송에 성공했을 때만 기록

**What to build:** 같은 빈자리에 대해 알림이 바퀴마다 반복되지 않게 한다. 새로 생긴 빈자리만 알리고, 사라졌다가 다시 생기면 다시 알린다. 재시작 직후 첫 알림은 "재시작 직후 현황"으로 표시한다. 전송에 실패한 빈자리는 다음 바퀴에 다시 보낸다. 영속 저장소는 두지 않는다. 근거: [spec](../../availability-poller/spec.md)

**Blocked by:** 01 (워킹 스켈레톤)

**Status:** done

- [ ] 같은 빈자리가 연속 두 바퀴 잡히면 알림은 첫 바퀴에만 간다.
- [ ] 빈자리가 사라졌다가 다시 나타나면 다시 알린다.
- [ ] 프로세스를 시작한 뒤 첫 알림에는 "재시작 직후 현황" 표시가 있다.
- [ ] Sink가 전송 실패를 흉내 내면 다음 바퀴에 같은 빈자리를 다시 보낸다.
- [ ] "알렸음" 상태는 알림 대상별로 따로 관리한다(키: 감시 조건, 자리, 입실일, 박수).
