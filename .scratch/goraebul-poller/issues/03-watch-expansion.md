# 03: 감시 조건을 조회 단위로 전개

**What to build:** 감시 조건 하나를 조회 단위 여러 개로 펼친다. 감시 조건은 입실일 범위, 요일, 최소 N박, 구역과 자리 필터로 이루어진다. 예약 창과 마감 규칙에 맞게 조회 대상을 고르고, 조회 결과를 자리 필터와 맞춰 빈자리를 만든다. 근거: [spec](../../availability-poller/spec.md)

- 조회 단위는 (시설, 구역, 입실일, 박수)다. 같은 단위를 여러 감시 조건이 쓰면 한 번만 조회한다.
- 자리 필터는 번호(`A02`)와 범위(`"A10-A15"`)로 쓴다. 생략하면 구역 안의 모든 자리가 대상이다. 설정 표기를 사이트 식별자와 어떻게 대응시킬지는 어댑터가 정한다.
- `describe()`에 오픈 규칙을 넣는다. 입실일 D는 D−30일 10:00에 열리고, 당일 입실은 18:00에 마감되며, 최대 2박이다.

**Blocked by:** 01 (워킹 스켈레톤)

**Status:** done

- [ ] 입실일 범위와 요일 필터에 맞는 날짜만 조회한다.
- [ ] `nights`를 생략하면 1박으로 조회하고, N을 주면 N박으로 조회한다.
- [ ] 감시 조건 두 개가 같은 조회 단위를 쓰면 요청은 한 번만 나가고, 결과는 두 감시 조건 모두에 반영된다.
- [ ] 자리 필터에 맞지 않는 빈 자리는 알리지 않는다.
- [ ] 아직 열리지 않은 날짜는 조회하지 않고, 가짜 시계가 오픈 시각을 지나면 조회를 시작한다.
- [ ] 당일 입실 단위는 18:00 이후 조회하지 않는다. 지난 날짜도 조회하지 않는다.
- [ ] 입실일 범위가 모두 지난 감시 조건은 만료 알림을 한 번 보내고 더 이상 조회하지 않는다.
