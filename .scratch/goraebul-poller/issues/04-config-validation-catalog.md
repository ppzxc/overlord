# 04: 설정 검증과 catalog CLI

**What to build:** 잘못된 설정으로는 폴러가 시작되지 않게 한다. 오류가 나면 어디가 틀렸는지, 어떤 값을 쓸 수 있는지를 알려 준다. 사용자가 고를 수 있는 구역과 자리 목록은 CLI로 확인할 수 있게 한다. 근거: [spec](../../availability-poller/spec.md)

**Blocked by:** 03 (감시 조건을 조회 단위로 전개)

**Status:** ready-for-agent

- [ ] zod로 구조를 검증한다. 필드가 없거나 형식이 틀리면 위치를 담아 시작을 거부한다.
- [ ] 없는 구역 코드나 자리 번호를 쓰면 쓸 수 있는 값 목록을 함께 보여 주고 시작을 거부한다.
- [ ] `nights`가 예약처의 최대 박수를 넘으면 거부한다.
- [ ] `pollIntervalSeconds`가 60보다 작으면 거부한다.
- [ ] 참조한 환경 변수가 비어 있으면 거부한다.
- [ ] `catalog goraebul`은 구역(코드, 이름, 유형, 정원)과 구역별 자리 번호를 표로 출력한다.
- [ ] `catalog goraebul --live`는 사이트를 한 번 조회해서 고정값과 실제 자리 목록의 차이를 보고한다. Transport를 교체해서 검증한다.
